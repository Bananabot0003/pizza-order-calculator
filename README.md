# Tony's Pizza Order Calculator

This is a simple pizza ordering program I made using Python for my programming class.

The program asks the customer for their pizza size, number of extra toppings, and delivery distance. It then calculates the total cost of the order.

## Pricing

- Small pizza: $8
- Large pizza: $12
- Extra toppings: $1 each
- Delivery: $2 for the first 5 miles and $1 for each additional mile
- Pickup: Free

## Python Concepts Used

- User input
- If and elif statements
- Functions
- Basic math
- F-strings

## How to Run

Run `pizza_order_cost.py` using Python 3 and follow the prompts.

This project was created to practice using Python to solve a basic business problem.
